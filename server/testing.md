The tests are written in the following files: "test_auth.py," "test_database.py," "test_main.py," and "test_summary.py". These files provide the test cases for auth.py, database.py, main.py, and summary.py, respectively. The test cases were written to achieve code and branch coverage. Each method was fully covered, as were all decision points for each method. For example, many of our methods throw exceptions, such as NoteDoesNotExistException. We tested that these exceptions were correctly thrown. The test cases for different branches were done in separate methods, so that they are clearly denoted. For example, one of the methods tested by "test_database.py" is store_note. So, we create the methods "test_store_note_success" and "test_store_note_user_does_not_exist." The latter ensures that a UserDoesNotExistException is thrown.
